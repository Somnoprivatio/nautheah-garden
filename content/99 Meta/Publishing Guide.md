# Publishing Guide

[[00 Home/Start Here|Home]]

This vault is built as plain Obsidian-compatible Markdown for player publication. It contains no dependency on private-vault paths and no ChatGPT-, system-, workflow-, or canon-audit tags.

## Publication boundary

- Publish this vault as its own repository or as the content directory of a static-site project.
- Do not merge the GM vault into the same published content tree.
- Review additions against [[00 Home/Reader Guide|Reader Guide]] before publishing.
- Treat images and PDFs in `90 Assets` as public handouts.

The notes use ordinary wikilinks and minimal frontmatter, a structure compatible with Obsidian and suitable for Quartz-style Markdown publishing.
