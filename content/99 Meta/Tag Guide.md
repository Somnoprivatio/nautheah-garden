# Tag Guide

[[00 Home/Start Here|Home]]

Tags are intentionally small and reader-oriented.

| Tag | Use |
| --- | --- |
| `index` | Navigation page |
| `world`, `place`, `nation`, `continent`, `region` | Geography |
| `people`, `official`, `shop` | People and public roles |
| `faction`, `government`, `noble-house`, `academy`, `druidic-order` | Organizations |
| `lore`, `legend`, `deity`, `calendar`, `maritime` | Setting knowledge |
| `history`, `news`, `threat`, `adventure` | Public events and warnings |
| `campaign/northern-current-carnies` | Active-campaign material |

Tags for private workflow, source ingestion, ChatGPT processing, game-system queries, canon review, or secrecy controls are intentionally absent.
