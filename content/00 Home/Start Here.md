# Nautheah Player Guide

Welcome to **Nautheah**, a world of far-reaching currents, island powers, continental capitals, old faiths, and adventuring work carried by public boards and newspapers.

This vault is a high-level, player-safe reference. It contains confirmed setting information, widely available records, and a separate chronicle of events witnessed by the active [[06 Campaign Lore/Northern Current Carnies/Campaign Overview|Northern Current Carnies]] party. It deliberately omits private character histories, hidden identities, secret motives, unresolved GM preparation, and the true answers behind active mysteries.
